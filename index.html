C in 60 seconds

Four ideas every C beginner meets first. Pick a tab.

A variable is a named box in memory. Its type decides what it can hold.

A loop repeats code. A for loop counts for you.

An array stores many values of one type under a single name. Counting starts at 0.

A function is a reusable block of code. It takes input and can return a result.
