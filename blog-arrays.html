How does an array work? How can one variable store many values?

A beginner’s guide to arrays in C.

C programming19 October 20264 min read

Introduction

In every programming language, we often need to store values of the same type. For example, a program might need to keep track of the marks of many students. If we create a variable for each mark, the code becomes long and hard to handle.

In the C programming language, an array gives us a way to solve this problem. It lets us store many values using just one variable name.

What is an array?

An array is a programming tool that stores a group of values of the same type in an orderly arrangement, one after another in memory.

Here marks is the name of the array, and 5 means it can hold five values.

Common mistakes

These four mistakes catch almost every beginner at least once.

  • Counting from 1. The first element is marks[0], not marks[1].
  • Going out of bounds. An array of size 5 has no marks[5]. The last index is 4.
  • Forgetting the & in scanf. Write scanf("%d", &marks[i]) to store the value.
  • Using values before setting them. A new array without values holds random leftovers.

Advantages of arrays

  • We can store many values using just one variable name.
  • It reduces the amount of code.
  • It works smoothly with loops.
  • It helps in doing calculations, searching and sorting.
One downside: an array usually holds values of the same data type, and its size cannot change after it is declared.

Conclusion

Arrays are one of the most important ideas in C programming because they give us a simple way to store and manage many related values. Instead of making many variables, we can use a single array and reach each value by its index.

When arrays are used with loops, they become even more powerful for handling large sets of data. From student marks to hotel prices and game scores, arrays are a basic idea with lots of practical uses.

Key takeaways
  • One array name can hold many values of the same type.
  • Indexes start at 0 and end at size minus 1.
  • Loops and arrays work best together.
  • The size is fixed when you declare the array.
