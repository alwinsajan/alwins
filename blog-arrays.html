How does an array work? How can one variable store many values?

A beginner’s guide to arrays in C with interactive memory visualizers.

C programming19 October 20265 min read

Introduction

In every programming language, we often need to store values of the same type. For example, a program might need to keep track of the marks of many students. If we create a variable for each mark, the code becomes long and hard to handle.

In C, an array gives us a clean way to solve this by storing multiple values using just one variable name.

What is an array?

An array is a data structure that stores a fixed-size sequential collection of elements of the same type in contiguous RAM memory.

How Arrays Live in Memory (Contiguous Storage)

Unlike loose variables scattered randomly in memory, array elements live directly next to each other. In 32-bit/64-bit systems, each integer int typically takes 4 bytes.

Formula for Memory Address:
Address of marks[i] = Base Address + (i * sizeof(int))

If base address is 0x2000:
  • marks[0] → 0x2000
  • marks[1] → 0x2004 (+4 bytes)
  • marks[2] → 0x2008 (+4 bytes)

Common mistakes to avoid

  • Counting from 1: The first item is always marks[0].
  • Array Index Out of Bounds: Declaring marks[5] gives valid indices 0 through 4. Accessing marks[5] results in undefined behavior!
  • Forgetting & in scanf: Always pass memory address: scanf("%d", &marks[i]);
